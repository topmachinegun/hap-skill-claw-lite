# OKR 视图配置

## 视图 1: 我的 OKR 看板

| 配置项 | 值 |
|---|---|
| 工作表 | 目标 O (okr_objective) |
| 视图类型 | 表格 |
| 过滤 | 负责人 = 当前用户 |
| 排序 | 所属周期(降序) → 状态(进行中优先) |
| 关联展示 | 子 KR 列表（内联展开），每个 KR 下展示里程碑数 |
| 可见字段 | 目标内容、状态、完成度(进度条)、所属周期、子KR数 |

## 视图 2: 季度 OKR 总览

| 配置项 | 值 |
|---|---|
| 工作表 | 目标 O (okr_objective) |
| 视图类型 | 看板（按周期分组） |
| 分组 | 所属周期 |
| 二级分组 | 负责人 |
| 卡片字段 | 目标内容、完成度(进度条)、状态 |
| 过滤 | 周期状态 != 已完成（或按需切换） |

## 视图 3: KR 进度录入

| 配置项 | 值 |
|---|---|
| 工作表 | KR 里程碑 (okr_milestone) |
| 视图类型 | 表单 |
| 默认值 | 提交人 = 当前用户，完成时间 = 今天 |
| 字段顺序 | 所属 KR → 完成值 → 说明 → 完成时间（隐藏提交人） |

## 视图 4: OKR 仪表盘

| 配置项 | 值 |
|---|---|
| 类型 | HAP 内置仪表盘 |
| 图表 1: 完成率 | 数值统计：当前周期所有 O 的平均完成度 |
| 图表 2: 成员进度 | 柱状图：按成员 → O 完成度 |
| 图表 3: KR 趋势 | 折线图：单个 KR 的里程碑累计趋势（目标值 vs 当前值） |
| 图表 4: 状态分布 | 饼图：O 的状态分布（进行中/已完成/已放弃） |
