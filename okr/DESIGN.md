# ClawCRM 个人 OKR 管理模块 - 设计文档

> 唯一事实源。所有数据模型、关联关系、视图定义、公式逻辑均以此文件为准。

## 设计边界

| 项 | 决策 |
|---|---|
| 层级 | 仅个人 OKR，无团队对齐 |
| 周期 | 月度 + 季度，月度 KR 支撑季度 O |
| 进度 | 基于里程碑记录自动汇总（SUM），非手动填 % |
| 审批 | 里程碑录入无需审批，成员直接提交 |
| 仪表盘 | HAP 内置仪表盘 |

---

## 1. 数据模型（4 张工作表）

### 1.1 OKR 周期 (okr_cycle)

管理季度和月度周期。季度周期挂载 O 目标，月度周期挂载 KR。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 周期名称 | 文本 | Y | "2026 Q2" / "2026-05" |
| 周期类型 | 选项 | Y | 月度 / 季度 |
| 开始日期 | 日期 | Y | |
| 结束日期 | 日期 | Y | |
| 状态 | 选项 | Y | 未开始 / 进行中 / 已完成 |
| 成员 | 成员(多选) | N | 本周期参与者 |

选项值：
- 周期类型: `month`(月度) / `quarter`(季度)
- 状态: `pending`(未开始) / `active`(进行中) / `closed`(已完成)

### 1.2 目标 O (okr_objective)

季度级目标，一个季度 2-5 个 O。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 目标内容 | 文本(多行) | Y | "提升客户拜访转化率" |
| 所属周期 | 关联→OKR 周期 | Y | 仅关联季度型周期 |
| 负责人 | 成员 | Y | |
| 完成度 | 数值(公式) | - | =AVG(子KR.完成度) |
| 状态 | 选项 | Y | 进行中 / 已完成 / 已放弃 |

选项值：
- 状态: `active`(进行中) / `done`(已完成) / `abandoned`(已放弃)

### 1.3 关键结果 KR (okr_key_result)

月度级关键结果，挂在 O 下。月度周期通过所属月字段关联。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| KR 内容 | 文本 | Y | "完成 20 次客户拜访" |
| 所属目标 | 关联→目标 O | Y | |
| 目标值 | 数值 | Y | 如 20 |
| 当前值 | 数值(公式) | - | =SUM(关联里程碑.完成值) |
| 单位 | 文本 | N | "次" / "%" / "万元" |
| 权重 | 数值 | N | 0~100，同 O 下 KR 权重和=100% |
| 完成度 | 数值(公式) | - | =MIN(当前值/目标值*100, 100) |
| 所属月 | 关联→OKR 周期 | Y | 仅关联月度型周期 |
| 负责人 | 成员 | Y | 默认继承 O 的负责人 |

### 1.4 KR 里程碑 (okr_milestone)

每次推进记录一条，自动汇总到 KR.当前值。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 所属 KR | 关联→关键结果 KR | Y | |
| 完成值 | 数值 | Y | 本次推进量 |
| 说明 | 文本(多行) | N | 推进描述 |
| 完成时间 | 日期 | Y | 默认创建日期 |
| 提交人 | 成员 | Y | 默认当前用户 |

## 2. 关联关系

```
OKR 周期(季度)
  └─ 目标 O (N:1)
       └─ 关键结果 KR (N:1)
            ├─ KR 里程碑 (N:1)
            └─ 所属月 → OKR 周期(月度)
```

关联字段类型均为 HAP「关联记录」类型，单条或多条。

---

## 3. 自动计算逻辑

| 计算项 | 公式逻辑 | 说明 |
|---|---|---|
| KR.当前值 | SUM(子里程碑.完成值) | 每次新增里程碑自动累加 |
| KR.完成度 | MIN(当前值/目标值*100, 100) | 0 除保护，上限 100 |
| O.完成度 | AVG(子KR.完成度) | 取所有子 KR 完成度的均值 |

## 4. 视图设计

| 视图 | 工作表 | 用途 | 关键配置 |
|---|---|---|---|
| 我的 OKR 看板 | 目标 O | 成员看自己的 O+KR 树 | 按负责人过滤；关联展示子 KR |
| 季度 OKR 总览 | 目标 O | 按周期查看所有成员 O | 按周期+成员分组 |
| KR 进度录入 | KR 里程碑 | 快速添加里程碑 | 表单视图，所属 KR 下拉选择 |
| OKR 仪表盘 | - | 聚合统计 | 完成率/超期/趋势图表 |

## 5. 实施步骤

| 步序 | 内容 | 产出 | 状态 |
|---|---|---|---|
| S1 | 在 ClawCRM 应用内建 4 张工作表 + 字段 | 表结构就绪 | ✅ 完成 |
| S2 | 配置关联关系（双向关联） | 关联链路通 | ✅ 完成 |
| S3 | 配置工作表公式 | 自动计算生效 | ⚠️ 需手动 |
| S4 | 创建视图 | 可用 | ⚠️ 需手动 |
| S5 | 录入样本数据验证 | 流程走通 | 🔲 待执行 |
| S6 | 可选：工作流通知 | 自动化 | 🔲 待执行 |

### S3 公式配置（需在 HAP 后台手动配置）

MCP API 不支持公式字段配置，以下三个字段需进入 ClawCRM 后台逐个设置：

1. **KR.当前值** → 在关键结果 KR 表中编辑「当前值」字段，设为公式，对子表「KR 里程碑」的「完成值」做 SUM
2. **KR.完成度** → 在关键结果 KR 表中编辑「完成度」字段，设为公式：`MIN(当前值/目标值*100, 100)`，需添加 0 除保护
3. **O.完成度** → 在目标 O 表中编辑「完成度」字段，设为公式：对子表「关键结果 KR」的「完成度」做 AVG

### S4 视图创建（需在 HAP 后台手动创建）

| 视图 | 工作表 | 类型 | 关键配置 |
|---|---|---|---|
| 我的 OKR 看板 | 目标 O | 表格 | 过滤：负责人=当前用户；排序列：所属周期、状态 |
| 季度 OKR 总览 | 目标 O | 看板 | 按所属周期分组；卡片显示目标内容、完成度 |
| KR 进度录入 | KR 里程碑 | 表格 | 显示列：所属 KR、完成值、说明、完成时间；隐藏提交人 |

仪表盘（完成率/趋势/分布图）使用 HAP 内置仪表盘功能搭建。
